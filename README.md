# 🕌 Ammar Quran Record — تلاوات عمار الخطيب

مكتبة صوتية كاملة للتلاوات بصوت **عمار الخطيب**، مقسّمة آية آية وجاهزة للاستخدام المباشر عبر روابط مباشرة.

هذا المستودع يهدف إلى أن يكون مرجعاً مفتوحاً ومجانياً لتلاوات قرآنية عالية الجودة، منظمة بنفس نظام ترقيم المصحف المعتمد عالمياً، بحيث يمكن لأي مطوّر استخدامها في تطبيقات القرآن، المواقع، أو أي مشروع آخر بسهولة تامة.

---

## 📂 هيكلة المستودع

```
├── 001/                  ← مجلد لكل سورة برقمها (3 خانات دائماً)
│   ├── 001.mp3           ← الآية الأولى
│   ├── 002.mp3           ← الآية الثانية
│   └── ...
├── 002/
├── ...
├── 114/                  ← الناس
│   ├── 001.mp3
│   ├── 002.mp3
│   └── 003.mp3
├── manifest.json         ← بيانات كل السور (الاسم + عدد الآيات)
└── README.md
```

**قواعد التسمية:**
- أرقام المجلدات والملفات بثلاث خانات دائماً: `001` ، `027` ، `114`
- كل ملف = آية واحدة كاملة بصيغة MP3

## 🔗 الروابط المباشرة

يمكن الوصول لأي آية مباشرة عبر الرابط:

```
https://raw.githubusercontent.com/AmmarBasha2011/Ammar-Quran-Record/main/{رقم_السورة}/{رقم_الآية}.mp3
```

**أمثلة:**
```
الفاتحة - الآية 1:
https://raw.githubusercontent.com/AmmarBasha2011/Ammar-Quran-Record/main/001/001.mp3

الإخلاص - الآية 3:
https://raw.githubusercontent.com/AmmarBasha2011/Ammar-Quran-Record/main/112/003.mp3

الناس - الآية 6:
https://raw.githubusercontent.com/AmmarBasha2011/Ammar-Quran-Record/main/114/006.mp3
```

## 📋 ملف manifest.json

يحتوي على بيانات السور الـ114 كاملة:

```json
{
  "001": {
    "name_ar": "الفاتحة",
    "name_en": "Al-Fatiha",
    "ayahs": 7
  },
  "112": {
    "name_ar": "الإخلاص",
    "name_en": "Al-Ikhlas",
    "ayahs": 4
  }
}
```

استخدمه للتحقق من عدد آيات أي سورة قبل جلب ملفاتها.

## ⚙️ كيف يتم التقسيم؟

تُسجَّل السورة كاملة في تسجيل واحد متصل، ثم يقوم سكريبت معالجة تلقائي بـ:

1. تحويل الصوت إلى نص بتوقيتات زمنية (نموذج `tarteel-ai/whisper-base-ar-quran` المتخصص في التلاوات)
2. مطابقة الكلمات مع نص المصحف الرسمي (رواية حفص عن عاصم) لتحديد حدود كل آية بدقة — حتى لو كانت الآيات متصلة بدون وقفات
3. قص كل آية في ملف مستقل والتحقق من العدد النهائي مقابل عدد الآيات الرسمي
4. رفع الملفات هنا بعد نجاح الفحص

> 💡 هذه الطريقة تعني أن النَفَس أو التوقفات داخل الآية لا تؤثر على دقة التقسيم إطلاقاً.
