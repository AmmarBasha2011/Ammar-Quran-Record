## ⚙️ كيف يتم التقسيم؟

تُسجَّل السورة كاملة في تسجيل واحد متصل، ثم خط معالجة من 5 مراحل:

1. **تحميل وتحويل** الصوت إلى MP3 128kbps
2. **تعرف كلامي بتوقيتات كلمات** — نموذج Whisper-small (CT2 int8, beam=5) المتخصص في العربية
3. **محاذاة عالمية (DP Alignment)** لمطابقة الكلمات المسماوعة مع نص المصحف الرسمي (حفص) بعد تطبيع الحروف — تحدد حدود كل آية حتى لو كانت متصلة بدون وقفات
4. **قص ذكي على الوقفات الطبيعية** — حدود الآيات تنزلق لأماكن السكوت الحقيقية في الصوت (ffmpeg silencedetect) فلا تتقطع كلمة أبداً
5. **فحص مستقل** — نموذج مختلف يعيد الاستماع لكل ملف منشور ويقارنه بالنص؛ أي آية مشكوك فيها تُضبط يدوياً قبل الاعتماد

> 💡 هذه الطريقة تعني أن النَفَس أو التوقفات داخل الآية لا تؤثر على دقة التقسيم إطلاقاً.

## 🛡️ ضمان الجودة

- ✅ كل سورة تفحص آليةً: عدد الملفات = عدد الآيات الرسمي
- ✅ كل آية تقارن نصياً بمطابقة تقريبية متسامحة مع أخطاء التعرف
- ✅ فحص مستقل ثانٍ بموديل مختلف بعد النشر
